통계역학에서 볼 수 있는 여러 간단한 시스템이 가질 수 있는 거시 상태와 미시 상태의 예제를 모아둔 노트

본격적으로 들어가기 이전에, 혹시 조합의 공식을 잊은 것은 아니겠지?

조합은 곧 N개 중 m개를 순서없이 고르는 경우의 수이다. 
구별가능한 N개를 순서대로 줄 세운 후, 
m개와 N-m개로 이루어진 그룹으로 나눈 다음, 
각 그룹 내부에서 순서가 의미없게 만드는 연산이다. 

그러므로 N개 줄세우기 경우의 수를 (m개 줄세우기 경우의 수 x N-m개 줄세우기 경우의 수)로 나누어준다.


$$N개 중 m개를 순서없이 고르는 경우의 수 = \binom Nm = _NC_m = \frac{N!}{m! \times (N-m)!}$$
[[Combination(math)]]

# 더 자세하게 계산해보기, Einstein solid

[[Stirling Approximation]]
이건 무조건 알고 있어야지. 
$$ln(n!) = n(ln(n)-1)$$
N이 oscillator수, q가 총 들뜬 에너지 수. 

 ($N \gg 1$, $q \gg N$) 이라고 전제. 

$$
\Omega(N, q) = \binom{q + N - 1}{q} = \frac{(q + N - 1)!}{q!(N - 1)!} \approx \frac{(q + N)!}{q!N!}
$$

로그를 취하면:

$$
\begin{align}
\ln\Omega(N, q) &= \ln(q + N)! - \ln q! - \ln N! \\
&\approx (q + N)\ln(q + N) - (q + N)  -q \ln q + q -N \ln N + N \\
&= (q + N)\ln(q + N) - q \ln q - N \ln N
\end{align}
$$

$q \gg N$이므로:

$$
\begin{align}
\ln\Omega(N, q) &= (q + N)\ln\left[q\left(1 + \frac{N}{q}\right)\right] - q \ln q - N \ln N \\
&= (q + N)\left[\ln q + \ln\left(1 + \frac{N}{q}\right)\right] - q \ln q - N \ln N
\end{align}
$$

여기서 $\frac{N}{q} \ll 1$이므로 **테일러 근사** $\ln(1 + x) \approx x$ (when $x \ll 1$)를 사용:

$$
\begin{align}
\ln\Omega(N, q) &\approx (q + N)\ln q + (q + N)\frac{N}{q} - q \ln q - N \ln N \\
&= N\ln\left(\frac{q}{N}\right) + N + \frac{N^2}{q}
\end{align}
$$

$q \gg N$일 때 $\frac{N^2}{q}$ 항은 무시:

$$
\ln\Omega(N, q) \approx N\ln\left(\frac{q}{N}\right) + N
$$

따라서:

$$
\Omega(N, q) \cong e^{N\ln(q/N)} \cdot e^N = \left(\frac{q}{N}\right)^N \cdot e^N = \left(\frac{eq}{N}\right)^N
$$

### 최종 결과

$$
\boxed{\Omega(N, q) = \frac{(q + N - 1)!}{q!(N - 1)!} \cong \left(\frac{eq}{N}\right)^N}
$$
