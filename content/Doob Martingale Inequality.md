# Doob Martingale Inequality

## Notation 정리

| 기호 | 의미 |
|------|------|
| $M_t$ | 마팅게일 확률과정 |
| $M_t^*$ | 최대과정: $\sup_{0≤s≤t} \|M_s\|$ |
| $\mathcal{F}_t$ | 마팅게일의 자연 filtration |
| $\lambda$ | 임계값 (threshold) |
| $p$ | 지수 ($p ≥ 1$) |
| $\|\|M_T\|\|_p$ | $L^p$ 노름: $(E[\|M_T\|^p])^{1/p}$ |
| $\tau_\lambda$ | 정지시간: $\inf\{t : \|M_t\| ≥ \lambda\}$ |

## Doob's Maximal Inequality

### 기본 형태 (Theorem 3.2.4)
연속 마팅게일 $M_t$에 대해, 모든 $p ≥ 1$, $T ≥ 0$, $\lambda > 0$에 대하여:

$$P\left[\sup_{0≤t≤T} |M_t| ≥ \lambda\right] ≤ \frac{1}{\lambda^p} \cdot E[|M_T|^p]$$

### 식의 구성 요소 분석

#### 1. **좌변**: $P[\sup_{0≤t≤T} |M_t| ≥ \lambda]$
**의미**: "시간 구간 $[0,T]$에서 마팅게일이 한 번이라도 임계값 $\lambda$를 넘을 확률"

**직관**: 
- $\sup_{0≤t≤T} |M_t|$: 전체 구간에서의 "최고점"
- 마팅게일이 얼마나 "폭발적으로" 클 수 있는가?

#### 2. **우변**: $\frac{1}{\lambda^p} \cdot E[|M_T|^p]$
**의미**: "종료시점 $T$에서의 크기로 최대값을 제어"

**핵심**: 
- 분자 $E[|M_T|^p]$: 마지막 값의 $p$-제곱 평균
- 분모 $\lambda^p$: 임계값의 $p$-제곱
- $p$가 클수록 더 강한 제어 
- *더 강한 제어라는 게, 우변 값을 더 줄여서 부등식을 더 확실하게 만들 수 있다는 뜻인가?*

## 부등식의 직관적 해석

### 1. **"꼬리 확률의 제어"**
```
큰 값이 나올 확률 ≤ 평균적 크기 / 임계값^p
```

**일상적 비유**: 
- 주식 투자에서 "최대 손실이 100만원을 넘을 확률"
- 평균 손실이 10만원이면, 그 확률은 최대 10%

### 2. **지수 $p$의 역할**
- **$p = 1$**: 기본적인 체비셰프 부등식 형태
- **$p = 2$**: 분산을 이용한 제어 (가장 일반적)
- **$p$ 증가**: 더 강한 제어, 하지만 $E[|M_T|^p]$ 계산 어려워짐

### 3. **시간 의존성**
부등식이 **모든 $T$에 대해** 성립:
- 짧은 시간: $E[|M_T|^p]$ 작음 → 확률 작음, 시간이 얼마 안 지날 수록 더 확실하게 확률을 예상할 수 있음음
- 긴 시간: $E[|M_T|^p]$ 커질 수 있지만 여전히 제어 가능

## 증명의 핵심 아이디어

### Step 1: 정지 시간 활용
$$\tau_\lambda = \inf\{t ∈ [0,T] : |M_t| ≥ \lambda\}$$

### Step 2: 마팅게일 성질 이용
$$E[M_T] = E[M_0] \text{ (마팅게일 성질)}$$

### Step 3: Optional Stopping Theorem
$$E[M_{T∧\tau_\lambda}] = E[M_0]$$

### Step 4: 집합에서의 적분 분리
$$\{|M_t| ≥ \lambda \text{ for some } t ∈ [0,T]\} = \{\tau_\lambda ≤ T\}$$

이 과정에서 마팅게일의 "공정성"이 핵심 역할을 합니다.

## 구체적 활용 사례들

### 1. **Itô 적분의 연속성 (Theorem 3.2.5)**
$$M_t = \int_0^t f(s,ω) dB_s$$

Doob 부등식을 사용하여:
$$P\left[\sup_{0≤t≤T} \left|\int_0^t f dB_s\right| ≥ \lambda\right] ≤ \frac{1}{\lambda^2} E\left[\int_0^T f^2 ds\right]$$

**결과**: Itô 적분의 연속성과 수렴성 증명

### 2. **확률과정의 수렴성**
마팅게일 수열 $\{M_n\}$에 대해:
$$P[\sup_n |M_n| ≥ \lambda] ≤ \frac{1}{\lambda^2} \sup_n E[M_n^2]$$

**응용**: 강법칙의 대수법칙, 마팅게일 수렴정리

### 3. **브라운 운동의 최대값**
$$P\left[\sup_{0≤t≤T} |B_t| ≥ \lambda\right] ≤ \frac{2T}{\lambda^2}$$

**실용적**: 브라운 운동이 얼마나 멀리 갈 수 있는지 예측

## 다양한 버전들

### 1. **$L^p$ 버전**
$$\left\|\sup_{0≤t≤T} |M_t|\right\|_p ≤ \frac{p}{p-1} \|M_T\|_p \quad (p > 1)$$

### 2. **일방향 부등식** 
양의 서브마팅게일 $X_t ≥ 0$에 대해:
$$P[\sup_{0≤t≤T} X_t ≥ \lambda] ≤ \frac{E[X_T]}{\lambda}$$

### 3. **이차변분 버전**
$$P\left[\sup_{0≤t≤T} |M_t| ≥ \lambda\right] ≤ \frac{E[\langle M, M \rangle_T]}{\lambda^2}$$

## 실제 계산 예시

### 예시 1: 브라운 운동
$B_t$는 브라운 운동, $T = 1$, $\lambda = 2$:

$$P\left[\sup_{0≤t≤1} |B_t| ≥ 2\right] ≤ \frac{E[B_1^2]}{4} = \frac{1}{4}$$

**실제값**: $P[\sup_{0≤t≤1} |B_t| ≥ 2] = 2P[N(0,1) ≥ 2] ≈ 0.046$

부등식은 $0.25$로 여유있게 상한을 제공!

### 예시 2: Itô 적분
$M_t = \int_0^t dB_s = B_t$ (단순한 경우):

$$P\left[\sup_{0≤t≤1} \left|\int_0^t dB_s\right| ≥ 3\right] ≤ \frac{1}{9}$$

## 부등식의 최적성

### 1. **Sharp한가?**
일반적으로 **최적이 아님**: 상수배 차이 존재

### 2. **언제 거의 최적인가?**
- 마팅게일이 "균등하게 분포"될 때
- 극값이 끝점에서 달성될 때

### 3. **개선된 버전들**
- **Azuma-Hoeffding 부등식**: 유계 차분 조건 하에서
- **Burkholder-Davis-Gundy 부등식**: 더 정교한 상수

## 물리적/직관적 해석

### 1. **"보험 원리"**
```
최대 손실 확률 ≤ 평균 손실 / 허용 손실^p
```

**의미**: 평균적으로 작은 변화를 보이는 시스템은 큰 변화를 보일 확률도 작다

### 2. **"에너지 보존"**
마팅게일의 "공정성" 때문에:
- 한 곳에서 크게 증가하면
- 다른 곳에서는 감소해야 함
- 전체적으로 "에너지"가 보존됨
*이거 무슨 말이지? 다른 곳이 어디지? 다른 시행? 다른 시간 시점? 다른 시행을 말하는 거 같은데? 한 시행에서 크게 증가하면, 그만큼 다른 시행에서는 크게 망할 확률도 있다는 뜻이지? 지금 서술에서 에너지라는 개념을 사용하는 게 적절한 거야?*

### 3. **"집중 현상"**
$$P[\text{극값}] \propto \frac{\text{평균 크기}}{\text{임계값}^p}$$

### 4. **안전 마진**
실제 확률보다 **여유있는 상한** 제공:
- 보수적 추정
- 안전한 의사결정 가능

## 한계와 주의사항

### 1. **상한만 제공**
- 정확한 확률은 주지 않음
- 때로는 과도하게 보수적

### 2. **마팅게일 조건 필수**
- 일반적인 확률과정에는 적용 불가
- 독립증분이나 공정성 조건 필요

### 3. **종료시점의 중요성**
- $E[|M_T|^p]$가 매우 클 경우 부등식이 무의미
- 적절한 $T$ 선택이 중요

## 관련 부등식들과의 관계

### 1. **Markov 부등식**과의 연결
Doob 부등식은 Markov 부등식의 **마팅게일 특화 버전**

### 2. **Chebychev 부등식**과의 관계
$p = 2$일 때 분산을 이용한 제어와 유사

### 3. **집중 부등식들**
- Azuma, McDiarmid, Hoeffding 부등식들의 기초

## 현대적 응용

### 1. **기계학습**
- 확률적 경사하강법의 수렴성 분석
- 온라인 학습 알고리즘의 성능 보장

### 2. **금융수학**
- VaR (Value at Risk) 계산
- 옵션 가격의 민감도 분석

### 3. **통계학**
- 경험과정의 균등 수렴성
- 부트스트랩 방법의 이론적 근거

## 실습적 활용 가이드

### 1. **언제 사용하는가?**
- 마팅게일의 최대값이 궁금할 때
- 확률과정의 "폭발" 가능성 평가
- 수렴성 증명에서

### 2. **$p$ 값 선택**
- $p = 1$: 계산 간단, 제어 약함
- $p = 2$: 균형잡힌 선택, 분산 활용
- $p > 2$: 강한 제어, 계산 복잡

### 3. **실제 계산 팁**
- $E[|M_T|^p]$를 먼저 계산
- 적절한 $\lambda$ 값 선택
- 실제 확률과 비교하여 부등식의 효율성 평가
