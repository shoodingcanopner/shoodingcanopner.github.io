### Sonnet 73

**thou mayst in me behold** (그대가 내 안에서 볼 수 있는) /
**boughs** (가지, 나무의 큰 가지) / 
**Bare ruin'd choirs** (앙상하게 폐허가 된 성가대석, 성당 지붕의 뼈대나 나무의 앙상한 가지를 은유) /
**twilight** (황혼) /
**fadeth** (fadeth, fadeth, 사라지다) /
**by and by** (곧, 점차로) /
**Death's second self** (죽음의 제2의 자아, 밤) /
**seals up all in rest** (모든 것을 안식으로 봉인하다) / 
**ashes of his youth** (그의 젊음의 재) /
**death-bed** (임종의 침대) /
**Consum'd with that which it was nourish'd by** (그것을 살찌웠던 바로 그것에 의해 소멸되다) /
**ere long** (머지않아)

| **영어 원문 (Original Text)**                               | **한국어 해석 (Korean Translation)**         |
| ------------------------------------------------------- | --------------------------------------- |
| That time of year thou mayst in me behold               | 그대가 내 안에서 볼 수 있는 그 시절은,                 |
| When yellow leaves, or none, or few, do hang            | 노란 잎이나, 아예 없거나, 몇 개만 매달려 있는 해의 때이네,     |
| Upon those boughs which shake against the cold,         | 찬 공기에 떨고 있는 가지들 위에,                     |
| Bare ruin'd choirs, where late the sweet birds sang.    | 한때 아름다운 새들이 노래하던 앙상하게 폐허가 된 성가대석이여.     |
| In me thou see'st the twilight of such day              | 그대는 내 안에서 해가 진 후 서쪽으로 사라져가는 하루의 황혼을 보네. |
| As after sunset fadeth in the west,                     | (해가 진 후 서쪽으로 사라져가는)                     |
| Which by and by black night doth take away,             | 곧이어 검은 밤이 앗아가 버릴 황혼을,                   |
| Death's second self, that seals up all in rest.         | 죽음의 제2의 자아인, 모든 것을 안식으로 봉인하는.           |
| In me thou see'st the glowing of such fire              | 그대는 내 안에서 그런 불꽃의 빛을 보네.                 |
| That on the ashes of his youth doth lie,                | 자신의 젊음의 재 위에 놓여 있는 불꽃을,                 |
| As the death-bed whereon it must expire                 | 그것이 꺼져야 할 임종의 침대처럼.                     |
| Consum'd with that which it was nourish'd by.           | 그것을 살찌웠던 바로 그 재(연료)에 의해 질식하여.           |
| This thou perceiv'st, which makes thy love more strong, | 그대는 이것을 깨닫네, 이로 인해 그대의 사랑이 더욱 강해지리니,    |
| To love that well which thou must leave ere long.       | 머지않아 떠나야 할 것을 더욱 잘 사랑하기 위하여.            |
|                                                         |                                         |

### Sonnet 116

**Admit impediments** (방해물을 용인하다, 결혼식 서약에서 유래) /
**alters** (변하다) /
**bends with the remover to remove** (떠나가는 자와 함께 굽어져 사라지다) /
**ever-fixèd mark** (영원히 고정된 표지, 등대나 곶) /
**tempests** (폭풍우) / 
**wandering bark** (방황하는 배) /
**Whose worth's unknown, although his height be taken** (그 가치는 알 수 없으나 높이는 측정될 수 있는 별, 북극성을 의미) / 
**Time's fool** (시간의 바보, 시간의 희롱에 놀아나는 대상) / 
**bending sickle's compass** (휘어지는 낫의 영역, 죽음 또는 시간을 상징하는 낫) /
**bears it out** (그것을 견디다) /
**edge of doom** (파멸의 끝, 세상의 종말) /
**upon me proved** (내게 틀렸다고 증명되다)

결혼식 축사로 자주 쓰임

| **영어 원문 (Original Text)**                            | **한국어 해석 (Korean Translation)**                |
| ---------------------------------------------------- | ---------------------------------------------- |
| Let me not to the marriage of true minds             | 진실한 마음들의 결합에 방해물을 용인하지 않으리.                    |
| Admit impediments. Love is not love                  | 사랑은 사랑이 아니네,                                   |
| Which alters when it alteration finds,               | 변하는 것을 발견할 때 변하거나,                             |
| Or bends with the remover to remove:                 | 떠나가는 자와 함께 굽어져 사라지는 사랑은.                       |
| O no; it is an ever-fixed mark,                      | 오, 아니! 사랑은 영원히 고정된 표지(이정표, light house)이니,     |
| That looks on tempests and is never shaken;          | 폭풍우를 바라보아도 결코 흔들리지 않네.                         |
| It is the star to every wandering bark,              | 그것은 모든 방황하는 배에게 길잡이가 되는 별이네,                   |
| Whose worth's unknown, although his height be taken. | 그 높이는 측정될 수 있어도, 그 가치는 알 수 없네.                 |
| Love's not Time's fool, though rosy lips and cheeks  | 사랑은 시간의 바보가 아니네, 비록 장밋빛 입술과 뺨이                 |
| Within his bending sickle's compass come;            | 그의 휘어지는 낫의 영역(시간에 대한 메타포) 안에 들어와도.             |
| Love alters not with his brief hours and weeks,      | 사랑은 그의 짧은 시간과 주일들로 변하지 않고,                     |
| But bears it out even to the edge of doom.           | 파멸의 끝까지 견뎌내네.                                  |
| If this be error and upon me proved,                 | 만약 이것이 오류이고 내게 틀렸다고 증명된다면,                     |
| I never writ, nor no man ever loved.                 | 나는 결코 시를 쓰지 않았을 것이며, <br>그 누구도 진정으로 사랑하지 않았으리. |
사랑은 시간에 대해 불변이다. 


### Sonnet 130

**mistress' eyes** (내 애인의 눈, 이 맥락에서는 연인) /
**Coral** (산호) /
**dun** (칙칙한 갈색, 짙은 회색) / 
**wires** (철사) / 
**damask'd** (다마스크, 붉은색과 흰색이 섞인 장미) / 
**cheeks** (뺨) /
**reeks** (지독한 냄새가 나다, 풍기다) /
**hath a far more pleasing sound** (훨씬 더 듣기 좋은 소리를 가졌다) /
**I grant I never saw a goddess go** (나는 여신이 걷는 것을 본 적이 없음을 인정한다) /
**treads on the ground** (땅을 밟고 걷다, 지극히 현실적인 존재임을 강조) /
**rare** (희귀한, 특별한) / 
**belied with false compare** (거짓된 비유로 속여 찬양하다)

| **영어 원문 (Original Text)**                          | **한국어 해석 (Korean Translation)**     |
| -------------------------------------------------- | ----------------------------------- |
| My mistress' eyes are nothing like the sun;        | 내 애인의 눈은 태양과 전혀 같지 않네.              |
| Coral is far more red than her lips' red;          | 산호는 그녀의 입술의 붉음보다 훨씬 더 붉고.           |
| If snow be white, why then her breasts are dun;    | 만약 눈이 희다면, 그녀의 가슴은 칙칙한 갈색이네.        |

| But no such roses see I in her cheeks;             | 그녀의 뺨에서는 그런 장미를 보지 못하네.             |
| And in some perfumes is there more delight         | 그리고 어떤 향수에서는 더 즐거움이 있네.             |
| Than in the breath that from my mistress reeks.    | 내 애인의 입에서 나는 냄새보다.                  |
| I love to hear her speak, yet well I know          | 나는 그녀의 말하는 소리를 좋아하지만, 잘 알고 있네.      |
| That music hath a far more pleasing sound;         | 음악이 훨씬 더 듣기 좋은 소리를 가졌음을.            |
| I grant I never saw a goddess go;                  | 나는 여신이 걷는 것을 본 적이 없음을 인정하네.         |
| My mistress, when she walks, treads on the ground. | 내 애인은 걸을 때 땅을 밟고 걷네.                |
