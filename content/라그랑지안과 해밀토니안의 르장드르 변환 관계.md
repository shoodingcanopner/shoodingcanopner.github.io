# 라그랑지안과 해밀토니안의 르장드르 변환 관계

## 기호 정리

| 기호 | 의미 |
|------|------|
| $L$ | 라그랑지안 (Lagrangian) |
| $H$ | 해밀토니안 (Hamiltonian) |
| $q_i$ | 일반화된 위치 좌표 (Generalized coordinate) |
| $\dot{q}_i$ | 일반화된 속도 (Generalized velocity) |
| $p_i$ | 일반화된 운동량 (Generalized momentum) |
| $F_i$ | 일반화된 힘 (Generalized force) |
| $T$ | 운동 에너지 (Kinetic energy) |
| $V$ | 퍼텐셜 에너지 (Potential energy) |
| $J$ | 작용 (Action) |
| $\delta$ | 변분 (Variation) |
| $t$ | 시간 (Time) |

## Overview

라그랑지안 역학과 해밀토니안 역학은 동일한 물리 시스템을 서로 다른 변수 공간에서 기술하는 방법이다. 해밀토니안은 라그랑지안을 일반화된 속도 $\dot{q}_i$의 공간에서 그것의 기울기(gradient)인 일반화된 운동량 $p_i$의 공간으로 **르장드르 변환(Legendre transformation)** 한 것이다. 이 변환은 열역학에서 내부에너지를 다른 열역학 함수로 변환하는 것과 정확히 같은 수학적 구조를 가진다.

## Euler-Lagrange 방정식 유도

### Hamilton의 변분 원리 (최소 작용 원리) → Euler-Lagrange equation 유도

우주에서 실제로 일어나는 올바른 시간 경로에서 작용 $J$는 극값이다. 
변분에 대한 기호로 $\delta$를 이용한다. 
작용 $\delta J = \int_{t_1}^{t_2} \delta L \, dt = 0$에서 식 유도를 시작한다. $\delta L$은 다음과 같이 테일러 전개된다:

$$\delta L = \frac{\partial L}{\partial q_i} \delta q_i + \frac{\partial L}{\partial \dot{q}_i} \delta \dot{q}_i$$

여기서 $\dot{q}_i$는 시간 $t$에 대한 함수이므로, $\delta \dot{q}_i = \frac{d}{dt} \delta q_i$이다.

### 부분 적분을 통한 유도

변분을 적분에 적용하면:

$$\delta J = \int_{t_1}^{t_2} \left[ \frac{\partial L}{\partial q_i} \delta q_i + \frac{\partial L}{\partial \dot{q}_i} \delta \dot{q}_i \right] dt = 0$$

두 번째 항에 부분 적분을 적용:

$$\int_{t_1}^{t_2} \frac{\partial L}{\partial \dot{q}_i} \delta \dot{q}_i \, dt = \left[ \frac{\partial L}{\partial \dot{q}_i} \delta q_i \right]_{t_1}^{t_2} - \int_{t_1}^{t_2} \frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right) \delta q_i \, dt$$

경계 조건 $\delta q_i(t_1) = \delta q_i(t_2) = 0$에 의해 (이것의 이름이 dirichlet boundary condition 이라고 한다.)
첫 번째 항은 사라지고:

$$\delta J = \sum_i \int_{t_1}^{t_2} \left[ \frac{\partial L}{\partial q_i} - \frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right) \right] \delta q_i \, dt = 0$$

### Euler-Lagrange 방정식

각 $\delta q_i$가 독립적이고 임의적이므로, 각 괄호 항이 개별적으로 0이어야 한다:

$$
\frac{\partial L}{\partial q_i} - \frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right) = 0 \tag{1}
$$

이것이 **Euler-Lagrange 방정식**이다.

## 일반화된 운동량과 일반화된 힘

### 일반화된 운동량 (Generalized Momentum)

정의:

$$
p_i = \frac{\partial L}{\partial \dot{q}_i} \tag{2}
$$

### 일반화된 힘 (Generalized Force)

Euler-Lagrange 방정식으로부터:

$$
F_i = \frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right) = \frac{\partial L}{\partial q_i} \tag{3}
$$

즉, **오일러-라그랑주 방정식은 일반화된 힘을 라그랑지안의 일반화 위치에 대한 편미분으로 나타낸다**.

## 르장드르 변환의 기하학적 의미

### 일반적인 르장드르 변환

함수 $f(x)$와 그 기울기 $p = f'(x)$ 사이의 관계에서:

$$f(x) + f^*\left(p\right) = px$$

여기서 $f^*(p)$는 $f(x)$의 르장드르 변환이다. 

이는 **기울기 $p$를 새로운 독립변수로 하는 함수로의 변환**을 의미한다.

## 해밀토니안의 정의와 유도

### 라그랑지안의 전미분

라그랑지안 $L(t, q_i, \dot{q}_i)$의 전미분:

$$dL = \frac{\partial L}{\partial t} dt + \sum_i \left( \frac{\partial L}{\partial q_i} dq_i + \frac{\partial L}{\partial \dot{q}_i} d\dot{q}_i \right)$$

Euler-Lagrange 방정식과 일반화된 운동량의 정의를 사용하면:

$$dL = \frac{\partial L}{\partial t} dt + \sum_i \left( F_i dq_i + p_i d\dot{q}_i \right)$$

### 해밀토니안의 르장드르 변환

**해밀토니안은 라그랑지안을 일반화된 속도 $\dot{q}_i$ 공간에서 일반화된 운동량 $p_i$ 공간으로 르장드르 변환한 것**:

$$
H(t, q_i, p_i) = \sum_i p_i \dot{q}_i - L(t, q_i, \dot{q}_i) \tag{4}
$$

### 기본 관계식

라그랑지안과 해밀토니안의 합:

$$
L + H = \sum_i p_i \dot{q}_i = 2T \tag{5}
$$

여기서 $T$는 운동에너지이다 (일반화 좌표가 선형 속도인 경우).

## 해밀토니안의 전미분과 Hamilton 방정식

### 해밀토니안의 전미분 유도

$d(L + H) = d(2T) = d(\sum p_i \dot{q}_i)$에서:

$$dL + dH = \sum_i (p_i d\dot{q}_i + \dot{q}_i dp_i)$$

앞서 구한 $dL$을 대입:

$$\frac{\partial L}{\partial t} dt + \sum_i (F_i dq_i + p_i d\dot{q}_i) + dH = \sum_i (p_i d\dot{q}_i + \dot{q}_i dp_i)$$

정리하면:

$$dH = -\frac{\partial L}{\partial t} dt + \sum_i (p_i d\dot{q}_i + \dot{q}_i dp_i) - \sum_i (F_i dq_i + p_i d\dot{q}_i)$$

$$dH = -\frac{\partial L}{\partial t} dt + \sum_i (\dot{q}_i dp_i - F_i dq_i)$$

### Hamilton의 정준 방정식 (Canonical Equations)

해밀토니안을 $H(t, q_i, p_i)$의 함수로 보면:

$$
dH = \frac{\partial H}{\partial t} dt + \sum_i \left( \frac{\partial H}{\partial q_i} dq_i + \frac{\partial H}{\partial p_i} dp_i \right)
$$

위 두 식을 비교하면:

**일반화된 속도 (Generalized Velocity)**:

$$
\dot{q}_i = \frac{\partial H}{\partial p_i} \tag{6}
$$

**일반화된 힘 (Generalized Force)**:

$$
F_i = -\frac{\partial H}{\partial q_i} \tag{7}
$$

**시간 편미분**:

$$
\frac{\partial H}{\partial t} = -\frac{\partial L}{\partial t} \tag{8}
$$

## 라그랑지안과 해밀토니안의 대응표 ⭐

이것이 핵심이다!

| 측면             | 라그랑지안 형식 ($L$)                                                                                     | 해밀토니안 형식 ($H$)                                                                                |
| -------------- | -------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| **정의**         | $L = T - V$                                                                                        | $H = T + V$                                                                                   |
| **독립변수**       | $(t, q_i, \dot{q}_i)$                                                                              | $(t, q_i, p_i)$                                                                               |
| **일반화 운동량/속도** | $p_i = \frac{\partial L}{\partial \dot{q}_i}$ (정의)                                                 | $\dot{q}_i = \frac{\partial H}{\partial p_i}$ (르장드르 변환)                                       |
| **일반화 힘**      | $F_i = \frac{\partial L}{\partial q_i}$ (Euler-Lagrange)                                           | $F_i = -\frac{\partial H}{\partial q_i}$ (Euler-Lagrange)                                     |
| **전미분**        | $dL = \frac{\partial L}{\partial t} dt + \sum_i (F_i dq_i + p_i d\dot{q}_i)$                       | $dH = \frac{\partial H}{\partial t} dt + \sum_i (- F_i dq_i + \dot{q}_i dp_i )$               |
| **운동방정식**      | $\frac{\partial L}{\partial q_i} = \frac{d}{dt}\left(\frac{\partial L}{\partial \dot{q}_i}\right)$ | $\dot{q}_i = \frac{\partial H}{\partial p_i}$, $\dot{p}_i = -\frac{\partial H}{\partial q_i}$ |

### 관계식

$$
L + H = \sum_i p_i \dot{q}_i = 2T \tag{9}
$$

$$
dL + dH = d\left(\sum_i p_i \dot{q}_i\right) \tag{10}
$$

## 물리적 해석

### 변수 공간의 변환

- **라그랑지안**: 위치-속도 공간 $(q_i, \dot{q}_i)$에서 시스템 기술
- **해밀토니안**: 위치-운동량 공간 $(q_i, p_i)$에서 시스템 기술 (위상 공간, Phase Space)

## 열역학과의 유사성

[[열역학 자연변수와 르장드르 변환]]과 정확히 같은 구조:

| 열역학 | 역학 |
|--------|------|
| 내부에너지 $U(S,V,N)$ | 라그랑지안 $L(q_i, \dot{q}_i, t)$ |
| Helmholtz 자유에너지 $F(T,V,N) = U - TS$ | 해밀토니안 $H(q_i, p_i, t) = \sum p_i \dot{q}_i - L$ |
| 온도 $T = \frac{\partial U}{\partial S}$ | 일반화 운동량 $p_i = \frac{\partial L}{\partial \dot{q}_i}$ |
| 엔트로피 $S$ ↔ 온도 $T$ | 일반화 속도 $\dot{q}_i$ ↔ 일반화 운동량 $p_i$ |
