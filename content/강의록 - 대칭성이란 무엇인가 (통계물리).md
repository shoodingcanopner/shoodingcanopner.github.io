# 오늘의 핵심

보통 상전이는 대칭성 깨짐이라고 말하지만, 대칭성 깨짐없는 상전이도 있다. 
핵심은 topology다. 라고 말하고 싶어서 하는 강의

Landau theory
자유에너지 극소점에서 F를 order parameter $\psi$에 대한 테일러 전개로 나타낼 수 있다. 

discretized symmetry는 order parameter가 1개의 값을 가지는 스탈라
continuous symmetry는 order parameter가 여러개의 값을 가진다. phase를 가져서 복소수하던가. 

![[Pasted image 20260105232131.png]]
continuous symmetry에서 나타나는 두 가지 요동의 방식
- Higgs mode
- Goldstone mode
