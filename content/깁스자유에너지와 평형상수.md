# 깁스자유에너지와 평형상수

## Overview

평형상수를 볼츠만 분포로 나타내라. 
평형상수하고 엔트로피 변화는?

화학 반응의 평형상수와 깁스 자유에너지 변화 사이의 관계를 볼츠만 분포로부터 유도한다.

## 기호 정리

| 기호 | 의미 |
|------|------|
| $H_A, H_B$ | 상태 A, B의 엔탈피 |
| $w_A, w_B$ | 각 에너지를 갖는 미시상태의 경우의 수 (degeneracy) |
| $K$ | 평형상수 |
| $\Delta H$ | 엔탈피 변화 $= H_B - H_A$ |
| $\Delta S$ | 엔트로피 변화 |
| $\Delta G$ | 깁스 자유에너지 변화 |
| $R$ | 기체상수 |
| $k_B$ | 볼츠만 상수 $= R/N_A$ |

## 볼츠만 분포와 평형

간단한 반응을 생각해보자:

$
A \rightleftharpoons B
$

분자가 상태 A에 있을 확률, 정확히는 $H_A$라는 엔탈피를 가질 확률은? 볼츠만 펙터에 미시상태 가짓수까지 곱해야 한다:

$
p(A) = w_A e^{\frac{-H_A}{RT}} \tag{1}
$

분자가 상태 B에 있을 확률도 마찬가지이다:

$
p(B) = w_B e^{\frac{-H_B}{RT}} \tag{2}
$

## 평형상수 유도

평형상수 $K = \frac{[B]}{[A]} = \frac{P(B)}{P(A)}$ 이고, $\Delta H = H_B - H_A$ 이므로:

$
K = \frac{[B]}{[A]} = \frac{P(B)}{P(A)} = \frac{w_B e^{\frac{-H_B}{RT}}}{w_A e^{\frac{-H_A}{RT}}} = \frac{w_B}{w_A} \cdot e^{\frac{-\Delta H}{RT}} \tag{3}
$

양변에 ln을 취하면:

$
\ln K = \ln\left[\frac{w_B}{w_A} \cdot e^{\frac{-\Delta H}{RT}}\right] = \ln\frac{w_B}{w_A} - \frac{\Delta H}{RT} \tag{4}
$

양변에 $-RT$를 곱하면:

$
-RT \cdot \ln K = -RT \cdot \ln\frac{w_B}{w_A} + \Delta H \tag{5}
$

## 깁스 자유에너지와의 연결

따라서:

$
\Delta G = \Delta H - RT \cdot \ln\frac{w_B}{w_A} = \Delta H - T\Delta S \tag{6}
$

여기서 $\Delta S = R \ln\frac{w_B}{w_A}$ (엔트로피는 미시상태 수의 로그에 비례)

결론은 다시,

$
\Delta G = -RT \ln K \tag{7}
$

## 결론

최종 결론은? 깁스 자유에너지 변화를 통해 반응 평형 상수를 알 수 있다~

평형상수가 크면 ($K > 1$) $\Delta G < 0$이고 반응이 생성물 쪽으로 자발적으로 진행된다.
평형상수가 작으면 ($K < 1$) $\Delta G > 0$이고 반응물 쪽이 더 안정하다.
